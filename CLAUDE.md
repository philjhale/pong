# Instructions

## README

`README.md` exists to help players understand how to play the game. If anything changes that affects gameplay — controls, scoring, win condition, how to run the game — update `README.md` to reflect it.

## Design doc

`docs/design.md` is the authoritative description of how the game works: mechanics, physics, architecture, and module responsibilities. Keep it up to date whenever the game changes. Anyone wanting to modify the game should be able to read `docs/design.md` and understand the current state before touching code.
