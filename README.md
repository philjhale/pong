# Retro Pong

Two-player Pong in the browser. First to 7 points wins.

## How to Play

Press **Enter** on the start screen to begin.

| Player | Move Up | Move Down |
|--------|---------|-----------|
| Left   | W       | S         |
| Right  | Arrow Up | Arrow Down |

Score a point by getting the ball past your opponent's paddle. The ball speeds up with each rally hit. First to **7 points** wins. Press **Enter** to play again.

## Running Locally

```bash
npx serve . -l 8080
```

Then open [http://localhost:8080](http://localhost:8080).

## Running Tests

```bash
npm test
```
